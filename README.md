# The House Of Wisteria Hotel Website

## Project Overview
The House Of Wisteria is a responsive luxury hotel website developed as part of a Frontend Web Development assignment. The website provides information about the hotel, room categories, facilities, image gallery, and an online booking form.

## Features
- Responsive design for mobile, tablet, and desktop
- Home page with hero banner
- About page
- Rooms page with six room categories
- Gallery page
- Booking page with form validation
- Mobile navigation menu
- Basic SEO (title, meta description, keywords, alt text)
- Clean and modern user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
